# Dotfiles - Setup a new Mac Device ready to work

This repository includes installation steps that

1. Install Homebrew.
2. Install all the packages using Brewbundle.
3. Sets up my neovim config using nvim config repo, if it does not exists
4. Sets up Oh-my-zsh, and configures the theme that I like
5. Sets up git config that utilises 1password backed ssh key
6. Sets up zed editor settings

It should help me ramp up a new working mac system upon running the install.sh
script.
